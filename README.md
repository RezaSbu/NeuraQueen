# NeuraQueen 👑

**NeuraQueen** — a conversational AI assistant built with **Next.js** and powered by artificial intelligence.

## Overview

NeuraQueen is an intelligent chatbot application designed to act as a customer assistant — answering questions and guiding users through a retail parts store catalog (StarCycle).

## Features

- Conversational AI responses
- Retail store assistant use case (motorcycle parts)
- Modern Next.js frontend

## Tech Stack

- Next.js
- TypeScript
- AI / LLM integration

## Getting Started

```bash
npm install
npm run dev
```
